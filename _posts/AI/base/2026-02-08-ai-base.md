## 什么是**大模型**

大模型并不是什么神奇的东西，它本质还是一个“可调用的函数”，由模型架构（网络结构）、分词器以及一组经过训练得到的数值参数（权重、偏置等）组成，用简单的比喻来理解：它像一个学会了技能的“数学函数”。

### 传统程序
从工程角度看，传统程序是“输入 → 固定指令序列 → 输出”，这些指令由开发者编写且可读：
```typescript
// 一个加法程序
function plus(a: number, b: number) {
  return a + b;
}
```

### 大模型
大模型的“行为”由内部的数值参数决定，这些参数是在大量数据上通过优化算法（例如梯度下降）学习出来的，而不是以可读代码的形式出现。推理阶段由深度学习框架（如 PyTorch、TensorFlow 或 ONNX 运行时）用这些参数执行数值计算来生成输出。训练/调优就是在数据上调整这些参数以改善模型表现的过程。

关键点：
- 组成：模型结构（规则）和很多数字参数（权重），还有把文字切分成小块的分词器。
- 学习：这些数字参数不是人写的，而是用大量数据训练出来的（类似反复练习学会技能）。
- 使用：把输入（比如一句话）传给模型，模型根据参数计算并返回输出（比如一段回答）。
- 训练 vs 推理：训练是调整参数让模型更“聪明”；推理是用训练好的参数做计算得到结果。

相比传统可读的程序代码，模型内部是数字和矩阵，不容易直接读懂，但它仍然是可以调用、可以运行的系统。

## 大模型开发

做 AI 建设目前主要是两方面，一个是开发大模型（做大脑），一个是开发利用模型的一系列工具（拼四肢）

### 开发大模型

开发大模型是一项专业性、理论知识要求极高的门槛的一个内容，涉及模型网络架构、算法、优化、等等一系列需要很高知识储备与能力的一项高难度工作...

### 开发大模型工具

开发可以更好利用大模型能力的各种工具，这是面相更广阔市场的内容。
