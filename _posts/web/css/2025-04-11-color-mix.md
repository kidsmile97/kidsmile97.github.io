## 屏幕里的内容世界

一个单纯颜色像素块拼接出来的世界，眼睛看到的世界同样如此，不过屏幕是发光，眼睛是受光而已。关于颜色你需要先理解以下两点

1. 颜色叠加：即多种颜色混合之后得到一种新颜色，比如最著名的三原色叠加，不同颜色颜料混合出新颜色等等。

2. 颜色叠加算法：计算机没有实物，它是怎么知道颜色混合之后会得到什么颜色呢？这时候就需要颜色叠加算法了。

> 计算机世界一切都是数字，颜色也是。定义 1 是红色，让后屏幕发光硬件接收到 1 就发出红色的光，颜色混合就是把颜色 1、2 通过算法计算得到颜色 3，然后发光。

> 屏幕显示颜色的最小单位是像素块，即一个发光单元显示一种颜色，这是由硬件决定的

屏幕渲染的所有内容，都是颜色的计算与叠加，最终你看到的每个像素点也只是一个颜色。现在你理解了像素点颜色最终由颜色叠加和叠加算法得出。

```html
<!-- 比如 rgb，其实就是一种颜色混合算法，当然 hsl 等等其他算法也一样 -->
<style>
  div {
    color: rgb(111, 222, 222);
  }
</style>
```

more: 透明度应该是属于算法的一种，它作为一个额外变量为算法提供多一个参数来计算最终颜色。

## mask：遮罩样式属性

mask 是 css 中一个比较有意思的样式属性，它实现的效果是什么呢？

> 用一个形状内容来定义元素的内容形状。

<iframe src="/assets/example/css/color-mix.html#second" style="height: 300px; width: 100%"></iframe>

```html
<style>
  .class {
    /* 图片遮罩 */
    mask: url() no-repeat center / cover;
  }
</style>
```

## mix-blend-mode：颜色混合样式属性

但我们本质并不是要换颜色，而是给图片的内容换颜色，但需要保留原来内容的纹理，那么下面有一个很重要的 CSS 样式属性你需要知道

```html
/**
 * 颜色混合模式
 * 这里用到 multiply 多颜色合并模式
 * 这个模式黑白色能够合并其它颜色，使得内容颜色深浅的纹理保留下来 
 */
mix-blend-mode: multiply;
```

前面说过，所有屏幕内容都是不同颜色像素块合并的显示，所谓内容的纹理也不过是一种颜色视觉。mix-blend-mode 说明的是颜色混合的算法

>  mix-blend-mode 属性混合的是 元素内容 + 父元素 + 元素背景 三者的颜色如何混合

比如元素内容是红色，给了黄色背景，父元素是蓝色，那么`mix-blend-mode`就是指定一种算法，混合这三个颜色。默认是不混合，直接显示最上层颜色。

## mask / background / mix-blend-mode 合用

其实你已经知道了：直接看效果
1. mask 切割了元素内容
2. background 定义颜色
3. mix-blend-mode 在 mask 的范围内混合 background 、父元素 的颜色

## 掌握了这些，换衣服颜色简直简单如喝水

```html
<div>
  <img alt="衣服整体照" />
  <div class="mask"></div>
</div>
<style>
  .mask {
    /* 对 img 完全覆盖 */
    position: absolute;
    left: 0;
    top: 0;
    mask: url() no-repeat center / cover;
    background-color: blue;
    mix-blend-mode: multiply;
  }
</style>
```
